## Available Scripts

In the project directory, you can run:

### `npm start` / `npm run dev`

Runs the app in development mode using Vite.\
Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

The page will hot-reload when you make changes.

### `npm test`

Launches the test runner (Vitest) in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.\
The build is minified and the filenames include content hashes.

### `npm run preview`

Serves the production build from the `build` folder locally, for a final check before deploying.
